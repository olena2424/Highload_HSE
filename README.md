# TikTok

## Тема и целевая аудитория

TikTok — сервис для создания и просмотра коротких видеороликов. Для каждого пользователя формируется персональная лента. Сервис популярен по всему миру.

### MVP

- Публикация видео
- Просмотр ленты
- Сбор статистики

### Целевая аудитория

На 2026 год MAU =  1.9 млрд.
DAU оценивается от 875 млн до 954 млн человек.
Самое больше количество пользователей в США (136 млн), далее идут Индонезия (108 млн) и Бразилия (91.7 млн). Россия на 7 месте с 56 миллионами активных пользователей в месяц [1].
